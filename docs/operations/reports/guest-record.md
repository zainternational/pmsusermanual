# Guest Record Report

The **Guest Record Report** shows the stay history and revenue statistics for a profile — an individual guest, a travel agent, or a company — across a date range.

:::tip **Having a problem?**
See the main [Troubleshooting](/general/troubleshooting) page for general issues, or the [Reports Overview](/operations/reports/overview) for how to run and export reports.
:::

## Access

From the sidebar, click **Report** → **Profile**, then choose **Guest Record** from the sub-report list.

## Filters

| Filter | Description |
|--------|-------------|
| Profile By | **All**, **Individual**, **Travel Agent**, or **Company**. Determines how stays are grouped/selected. |
| Profile | The specific individual, travel agent, or company profile (required when Profile By is not All). |
| Start Date / End Date | Date range to include qualifying stays. |

If **Profile By** is **All** (or no profile is selected), the report includes every qualifying stay in your hotel scope. **Individual** filters by the primary guest on the reservation; **Travel Agent** and **Company** filter by reservations attached to that agent/company profile.

## What the Report Shows

**Summary** at the top:
- Profile By and resolved Profile Name
- Date range
- Record Count — number of stay rows
- Total Nights
- Total Room Revenue, Total Food & Beverage Revenue, Total Other Revenue, Total Revenue

**Records table** — one row per qualifying stay:
- Reservation ID, guest/profile name, room number, room type
- Arrival date, departure date, nights
- Room revenue, food & beverage revenue, other revenue, total revenue for that stay

## Export

Use the export button (if available) to download as Excel or PDF.

## Common FAQs

**Why is Profile required for Individual / Travel Agent / Company?**
Without selecting a specific profile, the system cannot resolve which guest, agent, or company to filter by, so the report returns no records.

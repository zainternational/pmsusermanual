# Trial Balance Report

The **Trial Balance Report** shows the Opera-style daily trial balance snapshot for a selected night audit run: balance brought forward, revenue/non-revenue/payment sections by transaction code, guest ledger, deposit ledger, and balance carried forward.

:::tip **Having a problem?**
See the main [Troubleshooting](/general/troubleshooting) page for general issues, or the [Reports Overview](/operations/reports/overview) for how to run and export reports.
:::

## Access

From the sidebar, click **Report** → **Financial**, then choose **Trial Balance** from the sub-report list.

## Filters

| Filter | Description |
|--------|-------------|
| Start Date | Optional date range start to narrow the audit run list. |
| End Date | Optional date range end. |
| Audit Run | Select a specific night audit run to view its trial balance snapshot. |

You must select an **Audit Run** to generate the report. The audit run dropdown lists completed runs with their date and status.

## What the Report Shows

The report is a persisted **snapshot** taken at the time of that audit run (compute-on-read is disabled by default; if a run has no snapshot, it can be regenerated via a backfill), grouped into daily sections in this order:

- **Balance Brought Forward** — the guest ledger balance carried in from the prior audit run.
- **Revenue**, **Non-Revenue**, **Paid Out**, and **Payment** sections — each broken into rows by transaction code.

| Column | Description |
|--------|-------------|
| Code | Transaction code short code. |
| Account / Transaction | Transaction code name. |
| Balance | Net amount posted for that code within the section. |

Each section shows a section total. Below the sections:

| Field | Description |
|-------|-------------|
| Transaction Total Today | Sum of all sections for the audit date. |
| Deposit Ledger Activity | Net deposit ledger movement for the date. |
| Grand Total | Transaction total plus deposit ledger activity. |
| Balance Carried Forward | Closing guest ledger balance, carried forward to the next audit run. |

**Guest Ledger** panel: balance yesterday, charges, payments, deposits transferred at check-in, balance today.

**Deposit Ledger** panel: balance yesterday, deposits transferred at check-in, payments, balance today.

## How It Works

The trial balance snapshot is generated by the night audit trial balance processor when a night audit run completes, and is persisted (not recomputed on every view) so historical runs stay stable even if later configuration changes. The "Computed" timestamp shown on the report is when the snapshot was generated.

## Export

Use the export button (if available) to download as Excel or PDF (formatted to match the on-screen Opera-style layout) for accounting reconciliation.

## Common FAQs

**Why is the report empty?**
You must select an audit run from the dropdown. If no audit runs appear, night audit has not been run yet, or you may not have permission to view night audit data.

**"No trial balance data for this audit run" — what do I do?**
That audit run does not have a persisted snapshot (for example, it predates the snapshot feature). Ask an administrator to re-run night audit or run the trial balance backfill for that run.

# Guest Birthday Report

The **Guest Birthday Report** lists reservations for guests whose date of birth falls within a selected month/day range, so staff can plan birthday recognition for arriving or in-house guests.

:::tip **Having a problem?**
See the main [Troubleshooting](/general/troubleshooting) page for general issues, or the [Reports Overview](/operations/reports/overview) for how to run and export reports.
:::

## Access

From the sidebar, click **Report** → **Profile**, then choose **Guest Birthday** from the sub-report list.

## Filters

| Filter | Description |
|--------|-------------|
| Birth Date From / To | Filter by day/month of birth (year-independent). |
| Stay Start Date / End Date | Filter by reservations whose stay overlaps this range. |
| Reservation Status | Filter by reservation status (e.g. Confirmed, In House, Checked Out). |
| Sort Order | Sort results (e.g. by birthday date or guest name). |

Only guests with a recorded date of birth are included. If no filters are set, the report defaults to the current business date.

## What the Report Shows

Each row is one reservation for a guest with a birthday in range:

| Column | Description |
|--------|-------------|
| Reservation ID | Reservation number. |
| Guest Name | Guest name. |
| Room Number | Assigned room. |
| Company / Travel Agent | Attached company or travel agent name, if any. |
| Date of Birth | Guest's birth date (day/month highlighted). |
| Arrival Date / Departure Date | Stay dates. |
| Reservation Status | Current status. |

## Export

Use the export button (if available) to download as Excel or PDF for front office / guest relations use.

## Common FAQs

**Why is a guest with a birthday today missing?**
Their profile may not have a date of birth on file, or their reservation status/stay dates fall outside the selected filters.

# Districts

**Districts** is a standalone reference list (short code + name). It has **no parent link to State or City** in the current system — despite the name suggesting a "district within a state or city," there is no state/city selector anywhere in the create/edit form.

## Access

**Configuration → Profile → Districts**

## Fields

| Field | Description |
|-------|-------------|
| Short Code | Abbreviated code. |
| Name | District name. |

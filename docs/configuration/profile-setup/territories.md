# Territories

**Territories** is a standalone reference list (short code + name). It has **no parent link to Country or any other entity** in the current system — despite the name suggesting a "territory within a country," there is no country selector anywhere in the create/edit form.

## Access

**Configuration → Profile → Territories**

## Fields

| Field | Description |
|-------|-------------|
| Short Code | Abbreviated code. |
| Name | Territory name. |

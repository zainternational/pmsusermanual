# Visa Types

**Visa Types** are the categories of visas that guests may hold — for example, Tourist, Business, Transit, Diplomatic. They are stored on individual guest profiles for immigration and reporting purposes.

## Access

**Configuration → Profile Setup → Visa Type**

## Fields

| Field | Description |
|-------|-------------|
| Name | The visa type name (e.g. Tourist Visa, Business Visa, Transit Visa). |
| Short Code | Abbreviated code. |

:::note
There is no Active/Inactive field on Visa Types — every type that exists is available for selection.
:::

## Usage

Visa type is recorded on an individual guest profile along with visa number, issue date, and expiry date. This data appears in the [Guest Information Report](/operations/reports/guest-information) for immigration compliance.

# General Setup

General setup covers hotel information, system date, users, user groups, departments, job titles, license, cash register setup, TrackIt, and transportation types.

## Sub-items

| Sub-menu | Purpose |
|----------|---------|
| [Hotel Information](/configuration/general-setup/hotel-information) | Property details, address, contact, time zone, logo. |
| [System Date](/configuration/general-setup/system-date) | Business date used for reservations, rates, and reporting. |
| [Users](/configuration/general-setup/users) | User accounts, permissions, property assignment. |
| [User Groups](/configuration/general-setup/user-groups) | Permission sets and group assignment. |
| [Departments](/configuration/general-setup/departments) | Departments for reporting or access control. |
| [Job Titles](/configuration/general-setup/job-titles) | Job titles for users or profiles. |
| [License](/configuration/general-setup/license) | License status and activation. |
| [Cash Register Setup](/configuration/general-setup/cash-register-setup) | Cash registers for cashier login. |
| [TrackIt](/configuration/general-setup/trackit) | Overview of the 4 Track It tables (Groups, Types, Actions, Locations) for Lost & Found. |
| [TrackIt — Groups](/configuration/general-setup/trackit-groups) | Top-level item categories (Electronics, Clothing, Documents, etc.). |
| [TrackIt — Types](/configuration/general-setup/trackit-types) | Sub-categories within a group (Phone, Laptop, Passport, etc.). |
| [TrackIt — Actions](/configuration/general-setup/trackit-actions) | Actions taken on items (Found, Returned, Disposed, etc.). |
| [TrackIt — Locations](/configuration/general-setup/trackit-locations) | Where items were found or stored (Lobby, Room 101, HK Storage, etc.). |
| [Transportation Types](/configuration/general-setup/transportation-types) | Transportation types for pickup or guest transport. |
| [Services](/configuration/general-setup/services) | Additional services offered to guests (transfers, laundry, spa, etc.). |

Access via **Configuration → General Configuration** (or equivalent sub-menus).

## Related setup groups

General Setup covers property-wide and administrative options. Other configuration areas are documented separately:

| Group | Purpose |
|-------|---------|
| [Cashiering Setup](/configuration/cashiering-setup/overview) | Transaction codes, payment types, cashiers, articles, service charges, exchange rates. |
| [Housekeeping Setup](/configuration/housekeeping-setup/overview) | HK sections, attendants, tasks, lost & found, out-of-order, maintenance reasons/types. |
| [Reservation Setup](/configuration/reservation-setup/overview) | Room types/classes/rooms, reservation types, booking types, business segments, and reservation-related reason/code lookups. |

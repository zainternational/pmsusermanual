# License

There is currently **no License / activation screen** in this PMS. The system does not have a license key, activation status, or license management feature to configure.

If your sidebar or menu shows a "License" entry with no corresponding functionality, or you were expecting one, there is nothing to configure here today — access is controlled entirely through [Users](/configuration/general-setup/users) and [User Groups](/configuration/general-setup/user-groups) permissions, not a product license.

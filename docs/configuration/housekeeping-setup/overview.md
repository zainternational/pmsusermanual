# Housekeeping Setup

Housekeeping setup includes housekeeping sections, attendances, tasks, room management, lost & found reasons, management types, and out-of-order reasons.

## Sub-items

| Sub-menu | Purpose |
|----------|---------|
| [Housekeeping Sections](/configuration/housekeeping-setup/sections) | Sections (e.g. Floor 1, Tower A) to group rooms and assign tasks. |
| [Housekeeping Attendances](/configuration/housekeeping-setup/attendances) | Attendants or teams for task assignment. |
| [Housekeeping Tasks](/configuration/housekeeping-setup/tasks) | Task types (e.g. Clean, Deep Clean, VIP Setup). |
| [Room Management](/configuration/housekeeping-setup/room-management) | Room Maintenance Reasons — reasons used when logging a maintenance issue for a room (not a section/zone assignment tool). |
| [Lost & Found Reasons](/configuration/housekeeping-setup/lost-and-found-reasons) | Reasons for registering found items. |
| [Management Types](/configuration/housekeeping-setup/management-types) | Room status or maintenance classification. |
| [Out-of-Order Reasons](/configuration/housekeeping-setup/out-of-order-reasons) | Reasons for marking a room out of order. |

Access via **Configuration → HouseKeeping & Maintenance** (or equivalent sub-menus).

# Screen Basics

Features that work the same way on every screen in Hotelium PMS: quick search, keyboard shortcuts, table column control, and appearance.

:::note
This page is about **the application**. For how to use this manual website (its own search, printing, navigation), see [Using this manual](/general/using-this-manual).
:::

## Quick Search (jump to any screen)

Quick Search finds screens by name so you can jump straight there instead of walking the sidebar.

| Action | How |
|--------|-----|
| Open | Press **Ctrl+K** (**⌘K** on Mac), or press **/** when your cursor is not in a text field |
| Move through results | **↑** and **↓** |
| Open the highlighted result | **Enter** |
| Open it in a new browser tab | **Ctrl+Enter** (**⌘+Enter** on Mac) |
| Close | **Esc**, or press Ctrl+K again |

Results are grouped by module and show only the screens **your permissions allow** — if a screen you expect is missing, you most likely lack its view permission. Quick Search is not available on the login screen or before first-time setup is complete.

Quick Search finds **screens**, not guests or reservations. To find a booking or a profile, open the relevant list (Reservation, Individual Profiles, and so on) and use the search box on that screen.

## Keyboard Shortcuts

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+K** / **/** | Open Quick Search |
| **Ctrl+F2** | Open the Room Plan dashboard overlay from wherever you are |
| **Ctrl+F3** | Go to [Housekeeping → Room Plan](/operations/housekeeping/room-plan) |
| **Ctrl+F6** | Go to [Housekeeping → Room Chart](/operations/housekeeping/room-chart) |
| **Alt+A** | On a setup or list screen, open the **Add** dialog (only when you have the add permission and no other dialog is open). On [Night Audit](/operations/night-audit), it opens the Run Night Audit modal. |
| **Enter** | Submit the open dialog |
| **Esc** | Cancel/close the open dialog |

Screens that support Alt+A show the shortcut next to the **Add** button, so you can tell at a glance.

## Showing and Hiding Table Columns

Most list screens — reservations, cancellations, profiles, users, rates, in-house, checked-out, reports, journal by transaction — have a **column toggle** button above the table.

1. Click the column toggle. A checklist of the table's columns opens; the badge shows how many are currently hidden.
2. Tick or untick columns.
3. Click **OK** to apply, or **Reset** to return to the screen's default columns.

The choice applies while you stay on the screen. It is **not saved** — leaving the screen or reloading the page brings all default columns back, so set it again if you need the same layout later. Hiding a column only changes what you see on screen; it does not change what is exported or printed.

## Appearance (Light, Dark, System)

Open the **profile menu** (your name/avatar at the top of the screen) and choose:

| Option | Effect |
|--------|--------|
| Light Mode | Always the light colour scheme. |
| Dark Mode | Always the dark colour scheme. |
| System Default | Follows your computer's light/dark setting. |

The choice applies to your account on that browser only — it does not change anything for other users.
